## 이 문서. train_transaction 컬럼별 정리

`datasets/ieee-cis/train_transaction.csv` 590,540행 394열을 직접 집계한 결과다. 근거 수준은 다섯 단계로 적는다 — **공식**(주최 측 설명), **값에서 명백**(예외 없이 관측된 항등식·분포), **강한 추론**(관측이 일관되나 반례가 남음), **커뮤니티 추측**(상위권 솔루션의 해석, 데이터로 확정되지 않음), **확인 불가**(미공개이고 데이터로도 안 풀림). 결측률은 590,540행 기준이다.

### uid 정의

아래 수치 중 "같은 카드가 직전에 한 거래"를 따지는 것은 전부 이 조합을 쓴다. IEEE-CIS에는 카드를 알아볼 번호가 없어서, 있는 값들을 조합해 대신 쓴다.

```
uid = card1 + addr1 + (거래일 - D1)      # 거래일 = TransactionDT // 86400
```

4절에 적어둔 1위 솔루션 토론에서 온 커뮤니티 통설이고, 주최 측이 확인해준 것이 아니다. **어떤 키를 쓰느냐에 따라 수치가 크게 달라지므로 반드시 함께 적는다.** 예를 들어 D3이 "직전 거래로부터의 일수"와 일치하는 비율은 이 키로 74.77%인데, `card1 + addr1`만 쓰면 33.03%로 떨어진다. 키를 바꾸면 C-5·C-6의 일치율과 [공격 조건](attack-constraints.md)의 D-1의 창 어긋남 비율을 전부 다시 뽑아야 한다.

이 키가 D1을 재료로 쓰기 때문에 생기는 한계가 하나 있다. **D1이 리셋되면 uid도 새로 생기므로, D1 리셋 자체는 이 키로 관측되지 않는다.**

**달력 매핑(강한 추론).** 원점 2017-11-30, day1 = 2017-12-01. train은 2017-12-01~2018-05-31, test는 2018-07-01~2018-12-30이고 공백은 2018년 6월 한 달이다. 요일은 `(거래일 - 1 + 4) % 7`로 0이 월요일이다. 근거는 요일계수 최저 2요일이 인접한다는 제약, 잔차 최저일과 2018년 미국 공휴일의 일치, id_30·id_31에 적힌 버전이 실제 출시일과 앞뒤가 맞는지, 이렇게 셋이고, 세 필터의 교집합이 2017-12-01 단독이다.

**시간대는 UTC다.** train_identity의 id_14(UTC 오프셋)별로 거래량 트로프가 오프셋만큼 밀리고, 오프셋을 적용하면 네 그룹 전부 현지 03시에 트로프가 온다. 논문에는 "hour는 UTC 시"라고 명시한다.

블록 내부 평균 절댓값 상관은 0.26~0.55다. **339개 중 170개(50.1%)는 ProductCD로 존재 여부가 딱 끊긴다** — W에서 전무한 것이 159개, 비-W에서 전무한 것이 11개(V1-V11)다. [분류표](feature-taxonomy.md) 3절의 "ProductCD를 바꾸면 feature 체제가 바뀐다"는 이 수치로 뒷받침된다.

**금액 단위로 판정된 컬럼은 76개다**(V126-V137, V159-V166, V202-V216, V263-V278, V306-V321, V331-V339). 최댓값 범위는 3,300~641,511이라 여러 건의 합으로 보인다.

**카운트형과 금액형이 짝을 이룬다는 주장은 내린다.** 한때 "여섯 블록에 걸쳐 64쌍이 있고 전부 완전히 일치한다"고 적었으나 재현되지 않았다. 문서가 이름 붙인 짝 중 V167-V183↔V202-V216은 카운트 11개 대 금액 12개, V217-V237↔V263-V278은 16개 대 13개라 애초에 1:1 대응이 되지 않고, 금액형 76개 중 일부는 339개를 다 뒤져도 완전히 일치하는 카운트가 없다.

짝 목록이 없으면 [공격 조건](attack-constraints.md)의 D-2의 미해결 항목(금액형 V에 현재 거래 금액이 들어가는지)을 다시 계산할 수 없다. **그 항목을 실험 전에 확정하려면 짝을 먼저 다시 찾아야 한다.**

**V가 시각을 담고 있지는 않다.** hour와의 절댓값 상관 최대가 0.092, 요일과는 0.047이다. D9처럼 시각을 그대로 인코딩한 V는 없다.

**Vesta가 내부에서 카드를 어떻게 알아보는지는 공개된 컬럼으로 알아낼 수 없다.** 이 문서의 uid로 **처음부터 지금까지 다 센 값**을 만들어보면 0.1~3.3%밖에 안 맞는다. 다만 **최근 며칠만 센 값은 다르다** — 같은 조합으로 최근 24시간 거래를 세면 V95와 72.66%가 맞는다([분류표](feature-taxonomy.md) 5절). 이 둘을 같은 얘기로 묶으면 안 된다.
